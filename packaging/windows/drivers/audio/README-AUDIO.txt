XyDesk Virtual Audio & Virtual Mic Driver (VB-CABLE)
===================================================

Driver audio virtual berlisensi freeware dari VB-Audio Software (https://vb-audio.com/Cable/).
Digunakan untuk:
1. Menangkap output audio PC host untuk dikirimkan ke client Android/Web secara low-latency.
2. Meneruskan suara microphone dari client (HP/Tablet/Laptop) agar terbaca langsung sebagai perangkat input microphone fisik di Windows (CABLE Input -> CABLE Output), sehingga dapat langsung digunakan di Discord, Zoom, game multiplayer, dan aplikasi sistem lainnya tanpa konfigurasi manual.

Driver ini dipaketkan langsung di dalam installer XyDesk dan dipasang otomatis secara silent.
