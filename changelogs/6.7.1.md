# Changelog 6.7.1 - 2026-09-07

> Build 36. Fix VM/RDP hitam + audio mati + UI desktop redesign v3.0 Paper+Void

## Masalah yang dilaporkan
- Tes remote VM/GPU VM (Paperspace/RunPod/Vast) — tersambung tapi hitam, hanya Ms terbaca
- Driver audio/mic inout mati di VM tanpa device
- UI UX desktop jelek belum terganti
- Tes lab RDP via GitHub Actions — hitam karena RDP lock

## Ditambahkan
- **GDI fallback GetDC(0) + virtual screen**: `GdiCapture::baru()` coba `CreateDCW(DISPLAY)` dulu, kalau gagal fallback `GetDC(0)` + `GetSystemMetrics(SM_CXVIRTUALSCREEN=78, SM_CYVIRTUALSCREEN=79)`. Log `[xydesk-host] GDI fallback aktif`
- **DXGI fallback output pertama**: `DxgiCapture` kumpulkan first output yang berhasil DuplicateOutput, kalau exact DISPLAY tidak ketemu pakai fallback + log VM/RDP
- **Deteksi RDP session**: `is_rdp_session()` = GetSystemMetrics(SM_REMOTESESSION=0x1000), log di spawn_frame_source + watchdog
- **Audio real device check**: `capture_available()` cek `list_outputs().is_empty()` + `has_default_output()` bukan cuma cfg, tambah `has_default_output()` helper
- **Control API**: tambah `isRdpSession` boolean, `framesCaptured` sudah ada, sekarang jujur untuk VM
- **Desktop UI redesign v3.0 Paper+Void**: sidebar #0d0716 + radial ungu, topbar glass blur, card radius 20 shadow ungu, button primary gradient #7c3aed→#5b21b6, VM warning banners
- **Test Lab workflow**: anti-lock ScreenSaveActive=0, powercfg never, shortcut Disconnect-tanpa-lock.bat (tscon %SESSIONNAME% /dest:console), info koneksi jelasin kenapa hitam di RDP

## Diperbaiki
- `screen.rs` empty list handling: `start_gdi_monitor` & `start_dxgi_monitor` tidak Err lagi kalau list_displays 0, tapi pakai fallback virtual screen
- `audio.rs` capture_available misleading true di VM — sekarang false kalau tidak ada device
- `desktop/app/page.tsx` NEWS_IMAGE_BLOCK domain `xystudio.my.id` → `xydesk.my.id`
- Login desktop UI masih polos — redesign v3.1 hero + form (next 6.7.2)

## Dampak

- Di RDP lab, pakai tscon trick untuk disconnect tanpa lock, baru konek via XyDesk bukan RDP
