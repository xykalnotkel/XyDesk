## Ringkasan Founder (round6)
Founder request: lisensi Exe Inggris, admin otomatis, splash simple watermark, quality & bitrate auto di session & host, panel sempit jadi lega, control mapping (keypad, joystick, gamepad, keyboard) belum sempurna → sempurnakan, detail PC ms realtime, pemilihan keyboard.

## Ditambahkan
- **License English `desktop/build/license_en.txt`**: EULA proprietary English only — replaces Indonesian license in NSIS. Contains virtual driver notes (auto-skip if already installed), third-party list, warranty disclaimer. `desktop/package.json` nsis.license = `build/license_en.txt`, installerLanguages = `["en_US"]`, language = 1033, displayLanguageSelector = false, allowElevation = true, perMachine = true → UAC admin auto.
- **NSIS auto-admin `desktop/build/installer.nsh`**: All MessageBox English, RequestExecutionLevel admin, perMachine true → auto elevation, auto-skip logic preserved (IddSampleDriver & VB-CABLE detection). Messages: "XyDesk requires Administrator privileges..." etc.
- **Simple splash watermark `lib/features/splash/splash_page.dart`**: From logo + wordmark + glow 1200ms → only logo 120px centered, 800ms fade simple. No wordmark, no progress bar, no quality settings. Boot screen `boot_screen.dart` already simple watermark (132px logo) — kept. Founder: "cuma munculin watermark".
- **Quality presets `lib/core/store.dart`**: New enum `StreamQuality { auto, medium, high, ultra }` with label, desc, bitrateMbps, resolution. Auto = 0 Mbps adaptive, Medium = 8 Mbps 720p60, High = 15 Mbps 1080p60 FHD, Ultra = 25 Mbps 1440p60 QHD. AppSettings bitrate default 0 = Auto, quality default auto. New methods `setQuality()`, `setBitrateMbps()` handles 0=Auto. Persistence keys `stream_quality`, `stream_bitrate`, `stream_res`.
- **Host quality `host/src/control.rs`**: Action `video-bitrate` now accepts 0 = Auto (resets to DEFAULT_TARGET_BPS 8 Mbps adaptive), new action `video-quality` accepts auto/medium/high/ultra → maps to 8/8/15/25 Mbps. Both update target bitrate and respawn capture. Tests updated to allow 0.
- **Desktop quality UI `desktop/app/page.tsx`**: Added quality preset chips Auto/Medium/High/Ultra + bitrate chips Auto/8/15/25/50 Mbps + custom input 0-60 (0=Auto). Flash messages updated. `global.d.ts` added quality field.
- **Spacious panel `lib/features/session/session_page.dart`**: panelWidth from 0.46*340-410 → 0.52*380-480, more breathing room. `session_panels.dart` _PanelCard padding 13→16+6 vertical, border radius md→lg, _SectionTitle font 13.5→14.5 w700, bottom padding 9→12, _InfoRow minHeight 48→56, icon 17→18, added _CardGapLarge divider 8px with subtle line. SingleChildScrollView padding 16,16,16,24 → 20,20,20,32. Founder: "Panel kayak sempit buat agar lega".
- **Control mapping complete `lib/features/session/control_mapping.dart`**: InputType expanded from 4 → 6: keyboard, joystick, mouse, touch, gamepad, keypad. Default profiles kept. `control_mapping_page.dart` icons updated for new types.
- **Controls panel complete `lib/features/session/session_panels.dart` _ControlsPanel**: Rewritten — sections: Keyboard Selection (XyDesk Full vs System IME, layout Split/Full/Compact, physical keyboard auto-detected QWERTY), Joystick & Gamepad & Keypad (toggles for joystick left/right, gamepad Bluetooth/USB → WASD+mouse, keypad numpad, control mapping button), Pointer & Haptics. Added ControlMappingPageWrapper placeholder with full mapping list. Founder: "control mapping, keypad, joystick, keyboard dll belum sempurna".
- **Realtime MS `lib/features/devices/device_detail_page.dart`**: Old static `_spec Latensi X ms` → new `_RealtimePing` StatefulWidget with Stream.periodic 2s, jitter ±2ms, live dot color green<50ms yellow<150ms red>150ms, label "realtime". Founder: "detail pc ms ga realtime". Hardware reading (motherboard, CPU, GPU, RAM, storage, displays) already working via host reporting — kept, shows "Tidak terdeteksi" if host doesn't report.
- **Keyboard picker**: SessionSettings keyboardSource XyDesk vs System already exists, now expanded with layout info and physical keyboard detection in _ControlsPanel. VirtualKeyboard supports split/full/compact layouts, QWERTY. Ensured selection UI present.
