# 6.7.18 — Fix Panic No Reactor Running (Tauri Window Gagal Kebuka)

**Tanggal:** 2026-09-13
**Tipe:** fix — CRITICAL

## Ringkasan
- **Root cause `gada apa apa` saat `XyDesk.exe`:** `thread 'main' panicked at src/engine.rs:197:9: there is no reactor running` — `EngineSupervisor::start()` dipanggil di `lib.rs::run()` SEBELUM `tauri::Builder` bikin Tokio runtime, jadi `tokio::spawn` panic dan proses exit silent (karena `windows_subsystem = windows` hide console).
- **Fix:**
  - `desktop/src-tauri/src/engine.rs`: `tokio::spawn` (3 lokasi) → `tauri::async_runtime::spawn` — pakai runtime Tauri yang sudah ada.
  - `desktop/src-tauri/src/lib.rs`: `engine_supervisor.start()` dipindah ke dalam `.setup(move |app| { engine_supervisor.start(); ... })` — jalan di dalam context runtime Tauri, bukan di `run()` sebelum builder.

## Detail
- `lib.rs`: `.manage(engine_supervisor.clone())` + `.setup(move |app| { engine_supervisor.start(); let handle = app.handle(); tray... win.show() })`
- `engine.rs:197,305,330`: `tauri::async_runtime::spawn`

## Artefak
- `XyDesk-Setup-x64.exe` v6.7.18 — window pasti kebuka, engine jalan, `out` 32 files, `resources/engine/xydesk-host.exe` 16MB OK, WebView2 152 OK.
