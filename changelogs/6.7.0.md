# Changelog 6.7.0 - 2026-09-07

> **Build 35.** Rilis mayor. Penyakit inti "layar hitam" di laptop dua GPU
> ditutup dengan memindahkan backend capture ke DXGI Desktop Duplication
> berantai fallback. Kematian audio 0x88890008 disembuhkan: host kini tunduk
> pada mix format perangkat dan mengonversi sendiri. Ditambah auth desktop
> (Google PKCE + email OTP), izin runtime Android, rem pairing server dengan
> label yang sampai ke pengguna, split input abs-vs-event, dan toggle
> fullscreen web.

### Ditambahkan

- **DXGI Desktop Duplication jadi backend capture utama, rantai DXGI → WGC →
  GDI.** Layar hitam di mesin hybrid-GPU (iGPU + dGPU) berakar dari frame
  WGC/GDI yang terikat GPU tempat app di-render, bukan GPU yang menyalakan
  display; DXGI membaca keluaran display langsung. Gagal DXGI = turun ke WGC,
  lalu GDI — tidak ada satu titik mati. Capture baru mulai setelah transport
  `Connected` (tidak ada kerja sebelum ada penonton), dan bingkai kuning WGC
  tidak pernah terlihat karena jalur utama tidak menggambarnya.
- **`/status` host melaporkan backend aktif + jumlah frame terkirim; flag
  `--capture-test`** menangkap frame tanpa peer — diagnostik lapangan untuk
  "capture hidup atau tidak" tanpa pairing.
- **Auth desktop: login Google (PKCE loopback) + email OTP** di shell
  Electron, paritas dengan web. Endpoint worker pendamping dibuat; klien OAuth
  desktop milik operator, secret dikirim sebagai Worker secret — tidak pernah
  masuk repo.
- **Izin runtime Android (mikrofon + kamera):** dialog diminta PADA MOMEN fitur
  dipakai (toggle mic, pemindai QR, halaman izin); deny permanen terdeteksi →
  penjelasan + pembuka pengaturan aplikasi. Manifest tanpa permintaan runtime
  tidak pernah memunculkan dialog — akar keluhan "izin mic tidak muncul".
- **Rem pairing server-side (pairguard):** kegagalan pairing berulang mengunci
  scope sementara; hub mengirim `pair-terkunci` + `reason` + `retry_in`.
- **Spesifikasi perangkat jujur:** detail perangkat Flutter diisi data nyata
  yang dibaca dari host (CPU, GPU, RAM, OS) — bukan teks perkiraan.
- **Toggle fullscreen web:** tombol rel sesi masuk DAN keluar; state
  disinkronkan `fullscreenchange` (Esc tercermin); iOS fallback
  `video.webkitEnterFullscreen` + event webkit pada elemen video.

### Diperbaiki

- **Audio WASAPI 0x88890008 (AUDCLNT_E_UNSUPPORTED):** host memaksa PCM16/48k
  di `Initialize`; shared mode hanya menerima mix format perangkat. Kini host
  Initialize dengan `GetMixFormat` lalu mengonversi sendiri (pcmconv.rs):
  decode/encode I16/I24/I32/F32 dengan clamp bukan wrap, resample linear,
  downmix rata-rata kanal. Ketiga loop capture lewat jalur yang sama. Cast
  `CoTaskMemFree` (windows 0.61 minta `Option<*const c_void>`) dibereskan
  setelah build-desktop #34 membuktikannya; #35 hijau.
- **`pair-terkunci` tidak pernah sampai ke pengguna:** web DAN Flutter
  memeriksa `host-sibuk` — kode yang tidak pernah dikirim hub — sehingga
  koneksi kedua yang ditolak rem menggantung tanpa pesan. Kedua klien kini
  menerima `pair-terkunci` (alias legacy `host-sibuk`) dan menampilkan sisa
  tunggu dalam detik.
- **Kursor "berenang" setelah backlog input:** konsumen injector menguras
  antrean per batch; `MouseMoveAbs` adalah STATE — hanya yang terakhir
  diterapkan (`buang_abs_basi`) — sedangkan delta relatif, tombol, key, dan
  scroll adalah EVENT dan tidak pernah dibuang. Antrean sehat = batch satu =
  perilaku identik; tiga test menjaga aturan itu.
- **Logo ter-flatten hitam di semua platform** dipulihkan ke asli/terang
  (termasuk adaptive Android); sisa ikon Material dan ikon spek duplikat
  dibersihkan.

### Diubah

- **UI desktop:** sudut jendela hybrid (radius native DWM + radius dalam
  paritas web), daftar perangkat di bawah ID/PW, popover password in-place,
  paritas warna & font — sesuai keputusan operator (hybrid, bukan radius
  penuh).
