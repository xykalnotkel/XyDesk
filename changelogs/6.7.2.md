# Changelog 6.7.2 - 2026-09-07

> Build 37. Virtual Display + Virtual Mic driver seperti AnyDesk/RustDesk + NSIS auto-installer + auto-skip jika sudah ada + UI fixes

## Ringkasan Founder (2026-09-07)
Driver virtual biar tidak hitam di VM/RDP dan mic denyut di Recording — tapi kalau PC/VM/RDP sudah ada driver, jangan reinstall, lewatkan. Ini yang diminta Founder round5.

## Auto-cek driver (Founder request — DONE)
- **NSIS `desktop/build/installer.nsh`**: `InstallVirtualDisplayDriver` cek `pnputil /enum-drivers | findstr IddSampleDriver` — kalau ada skip. `InstallVirtualAudioDriver` cek `Get-PnpDevice -Class AudioEndpoint *CABLE* | Measure-Object Count` >0 — skip.
- **Rust `host/src/virtual_display.rs`**: `is_driver_installed()` cek 3 cara: `EnumDisplayDevicesW` loop semua display, `pnputil /enum-drivers` cari IddSampleDriver, file `.inf` di `C:\Windows\INF`. `ensure_display()` early return jika installed.
- **Rust `host/src/virtual_mic.rs`**: `get_status()` → `hasVirtualInput`/`hasVirtualOutput` via `list_inputs_detailed()`/`list_outputs_detailed()` cari CABLE/VoiceMeeter/Virtual. `ensure_virtual_mic()` skip install jika sudah ada.
- **Hasil**: PC yang sudah ada VB-CABLE atau VDD tidak akan reinstall tiap update — installer hanya log "sudah ada — skip".

## Ditambahkan
- **Virtual Display Driver module `host/src/virtual_display.rs`**: deteksi headless/RDP, cek driver terinstal via pnputil / EnumDisplayDevices / file .inf, is_admin via TokenElevation, try_install_driver via pnputil /add-driver /install, ensure_display dipanggil di spawn_frame_source, create_virtual_display via VirtualDisplayDriver.exe
- **Virtual Mic Driver module `host/src/virtual_mic.rs`**: deteksi VB-CABLE / VoiceMeeter / Virtual, get_render_device_id prioritas CABLE Input → VoiceMeeter Input → fallback speaker, ensure_virtual_mic log render_target, try_install_driver cari VBCABLE_Setup_x64.exe
- **Audio detailed listing**: `list_outputs_detailed()` + `list_inputs_detailed()` baca friendly name via IPropertyStore PKEY_Device_FriendlyName {A45C254E-DF1C-4EFD-8020-67D146A850E0},14, device_by_id via HSTRING → PCWSTR, render_loop sekarang coba virtual cable biar denyut di Recording
- **Control API**: tambah `virtualDisplay: {needed, installed, isAdmin}` dan `virtualMic: {needed, installed, hasVirtualInput, hasVirtualOutput, renderTarget}`
- **Desktop UI**: HomePage banner virtual display hijau/ungu + virtual mic banner 🎙️/🔈 dengan render_target, Audio card jelasin kenapa tidak denyut (render ke speaker vs CABLE Output)
- **NSIS auto-installer `desktop/build/installer.nsh`**: customInstall macro check admin, copy driver scripts, check RDP via GetSystemMetrics, install VDD via bundled exe /S atau Scoop idd-sample-driver, install VB-CABLE via bundled zip/exe atau PowerShell, perMachine=true UAC admin, extraResources driver folder
- **Electron main.cjs**: checkAndInstallDrivers() log driver path + deteksi RDP via PowerShell, dipanggil di whenReady
- **Driver installers**: `host/driver/install.ps1` auto-download VDD dari GitHub releases, `install-audio.ps1` auto-download VB-CABLE dari vb-audio.com
- **Android adaptive icon**: background #F5F3FF → #0d0716 Void, regenerate foreground transparent X 108-432px, legacy ic_launcher.png Void
- **Android nav & billing icon**: pubspec tambah assets/img/nav/, _NavIconImage fallback bukan circle ring tapi Lucide house/cable/newspaper/user + accent, _BillingIconButton fallback container ungu + coins icon
- **Desktop login redesign v3.1**: 2 kolom hero Void + radial ungu + logo watermark + ilustrasi 3 row (DXGI+GDI Fallback, WASAPI, NVENC) + form card logo 40px jelas, mobile hero hide

## Cara pakai driver
- VM/RDP: download https://github.com/itsmikethetech/Virtual-Display-Driver/releases → Setup.exe admin → restart XyDesk
- Audio: download https://vb-audio.com/Cable/ → VBCABLE_Setup_x64.exe admin → reboot → pilih mic = CABLE Output di Discord/Zoom/Game
- Lab RDP: driver IddSampleDriver auto-install via Scoop di workflow test-lab.yml
