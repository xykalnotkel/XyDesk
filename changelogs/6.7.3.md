## Diperbaiki
- **Android update check bug `lib/features/notifications/update_repository.dart:188`**: Sebelumnya `updateAvailable = isAndroid ? manifest.buildNumber > installedBuild : compareVersions >0` — hanya cek buildNumber. Jika pubspec 6.7.0+35 → 6.7.1+35 (version naik tapi build sama karena lupa bump), `updateAvailable` false → UI "Anda memakai versi terbaru" dan tombol tidak berubah jadi Download. Fix: `final versionCompare = _compareVersions(manifest.version, installedVersion); final updateAvailable = isAndroid ? (versionCompare >0 || manifest.buildNumber > installedBuild) : versionCompare >0;` — sekarang version naik saja sudah trigger update, build naik juga trigger. Tombol Download muncul benar.
- **Session screen Loading Connection di dalam SessionPage `lib/features/session/session_page.dart`**: Sebelumnya `_connecting=true` + `_connectTimer 450ms` + `_ConnectingView` "Menyiapkan preview" — user sudah masuk session screen tapi masih loading palsu. Request Founder: "Session screen jangan Loading Connection di dalam — sebelum benar-benar terhubung jangan masuk session screen, kalau gagal jangan pernah masuk". Fix: hapus timer 450ms, `_connecting` init false, kalau `initialTransport` sudah negotiating/connected langsung live, kalau rejected/offline/busy/error auto-pop dengan SnackBar dan tidak pernah masuk session. `ConnectPage` sudah validasi pairing dulu (negotiating/connected baru push SessionPage), jadi SessionPage sekarang langsung video tanpa loading palsu. Placeholder `_RemoteScreenPlaceholder` menampilkan status transport asli (MENGHUBUNGI HOST, NEGOSIASI, GAGAL) bila belum live.
